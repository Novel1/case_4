# Кейс-задача №4 — Sulpak Notes (мобильное приложение для заметок)

## Что это

Веб-приложение (PWA — Progressive Web App) для создания, редактирования,
удаления и поиска заметок в рамках работы организации (совещания, собрания,
конференции). Работает как настоящее мобильное приложение: открывается
в браузере на телефоне и добавляется на главный экран («Установить» /
«Добавить на экран Домой») — иконка, полноэкранный режим, работа офлайн.

Технически — это **кроссплатформенное** решение (iOS и Android одновременно,
без отдельной разработки под каждую платформу и без публикации в App Store /
Google Play), что полностью закрывает пожелание задания о поддержке двух
платформ.

## Запуск / тестирование (для научного руководителя)

Есть два равноценных способа открыть приложение:

1. **Файл `index.html` напрямую** — скачать папку `case4_notes_app`,
   дважды кликнуть по `index.html`. Откроется в браузере по умолчанию,
   все функции работают полностью (включая сохранение заметок в файл).
2. **Через локальный сервер** (если браузер блокирует что-то при
   открытии file://):
   ```bash
   cd case4_notes_app
   python -m http.server 8000
   # открыть http://localhost:8000/index.html
   ```
3. **На телефоне**: разместить `index.html` на любом хостинге/файлообменнике
   со статической раздачей (или открыть по локальной сети через IP
   компьютера, пока оба устройства в одном Wi-Fi) — открыть в Chrome/Safari
   → меню → «Добавить на экран "Домой"».

Файл полностью самодостаточен: в него встроен движок SQLite, скомпилированный
в WebAssembly (библиотека sql.js) — интернет для работы не требуется, ничего
докачивать не нужно.

## Функциональность

| Функция | Как пользоваться |
|---|---|
| Создание заметки | кнопка «+» внизу справа → заголовок + текст → «Сохранить» |
| Редактирование | значок ✎ на карточке заметки |
| Удаление | значок 🗑 на карточке заметки (с подтверждением) |
| Поиск | строка поиска вверху — ищет по заголовку, тексту и дате |
| Хранение №1 — база данных | вкладка «База данных (SQLite)» — все заметки лежат в настоящей SQLite-базе (движок sql.js), которая сохраняется в хранилище браузера и переживает перезапуск |
| Хранение №2 — файлы устройства | вкладка «Файлы устройства» — каждую заметку можно скачать как отдельный `.txt`-файл (⬇) и позже загрузить обратно («Выбрать файл») — например, чтобы передать заметку коллеге или перенести на другое устройство |

## Архитектура и файлы

| Файл | Назначение |
|---|---|
| `index.html` | **Готовый к использованию** самодостаточный файл приложения (собран из файлов ниже) |
| `style.css` | Стили интерфейса, адаптивная мобильная вёрстка, светлая/тёмная тема |
| `app_logic.js` | Логика: CRUD-операции с SQLite через sql.js, поиск, экспорт/импорт файлов, обработчики UI |
| `build.py` | Скрипт сборки — встраивает CSS, движок sql.js и app_logic.js в единый `index.html` |
| `generate_mockups.py` | Генератор иллюстраций для этого руководства |
| `node_modules/sql.js` | Зависимость — SQLite, скомпилированный в WebAssembly (`npm install sql.js`) |

Пересобрать `index.html` после правок в `style.css`/`app_logic.js`:
```bash
python build.py
```

## Проверено (функциональное тестирование)

Через прямое выполнение сценариев в браузере (эквивалент ручного
тестирования пользователем) подтверждено:

- создание нескольких заметок и их отображение в списке — ✅
- поиск по подстроке из текста заметки — ✅
- редактирование заметки с обновлением списка — ✅
- отображение заметок во вкладке «Файлы устройства» — ✅
- удаление заметки — ✅
- **сохранение данных между перезагрузками страницы** (заметка осталась
  на месте после полного обновления страницы — подтверждает, что хранение
  в SQLite действительно постоянное, а не только в оперативной памяти) — ✅
